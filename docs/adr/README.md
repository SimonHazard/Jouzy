| [0003](0003-cloudflare-access-admin-auth.md) | Cloudflare Access plus rôles applicatifs pour l'admin | Accepté |
| [0004](0004-markdown-controlled-embeds.md) | Markdown sans HTML/MDX et directives d'embed contrôlées | Accepté |
| [0005](0005-privacy-analytics-external-media.md) | Web Analytics sans cookie et chargement explicite des médias tiers | Accepté |
| [0006](0006-wrangler-over-alchemy.md) | Better-T-Stack pour le scaffold, Wrangler pour Cloudflare | Accepté |
